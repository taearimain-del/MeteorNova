# Meteor-Nova
This is a Meteor Client addon for 6b6t that focuses on cpvp in particular 1.21.11~

## Download

The built addon is in [`dist/`](dist/):

- `meteor-nova-1.2.1.jar` — drop this into your `mods` folder alongside Meteor Client
- `meteor-nova-1.2.1-sources.jar` — sources, not needed to play
- `SHA256SUMS.txt` — checksums

Requires Minecraft 1.21.11, Meteor Client 1.21.11-86, Fabric Loader 0.19.3 and Java 21.

## Building

    ./gradlew build

The jar lands in `build/libs/`.
